システムにさせたいことは決まっていますよね。別のカーネル、見栄えのよいログイン画面、統一感のあるテーマ、整理されたサービス。ATT はそのすべてをひとつのウィンドウにまとめ、実行する前に何をするのかを正確にお伝えします。隠しごとも魔法もなく、コマンドはあなたが学べるように手元に残ります。

無料でオープン · nemesis_repo からインストール · Arch および Arch ベースのシステムで動作

ATT が選ばれる理由

ブラックボックスにはしません

システムツールで何より困るのは、マシンに何をされたのか分からないことです。ATT はその逆で、すべての操作が自らを説明し、コンソールの出力は読んで学び、次回は自分で実行できるように表示されます。

  • 実行前 何かに手を加える前に、その操作で何が変わるのかを、確認ダイアログや分かりやすいラベルで確認できます。
  • 実行中 進行状況、現在のステップ、リアルタイムのコンソール出力と、実行の様子をその場で見られます。
  • 実行後 実際に何が変わったのか、書き込まれたファイル、インストールされたパッケージ、操作されたサービスの概要が表示されます。

インストール

2 ステップで準備完了

ATT は、署名付きの pacman リポジトリ nemesis_repo から配布されています。リポジトリを一度追加すれば、あとは他のパッケージと同じようにインストールできます。以下はすべて通常のコマンドで、実行前に内容を確認できます。

ステップ 1：/etc/pacman.conf にリポジトリを追加

[nemesis_repo]
Server = https://erikdubois.github.io/$repo/$arch

スクリプトの方がよいですか？ 同じことを行います

$ curl -sL bit.ly/nemesis-repo | sudo bash
署名について。 nemesis_repo は Kiro の鍵で PGP 署名されており、kiro-keyring を通じて信頼され、グローバルな SigLevel を継承します。キーリングをインストールする前にリポジトリを手動で追加する場合は、キーリングが入るまでの間、このリポジトリに SigLevel = Optional を設定してください。

ステップ 2：更新してインストール

$ sudo pacman -Sy
$ sudo pacman -S archlinux-tweak-tool

あとはアプリケーションメニューから ArchLinux Tweak Tool を起動するだけです。管理者権限を求めるのは、操作が本当に必要とするときだけです。

互換性

Arch のために作られ、Arch ベースのシステムにもなじみます

ATT は ArcoLinux で生まれ、現在は素の Arch と、Artix、Manjaro、CachyOS、Kiro など、人々が実際に使っている Arch ベースのシステムで動作します。ディストリビューションが独自のやり方をしている場合でも、ATT はそれを検出してインターフェースを合わせます。

  • 必要なもの： Arch または Arch ベースのシステム、Python 3.8 以降、GTK 4.6 以降、そして pacman。
  • 一部のページでは任意： パッケージ操作用の alacritty、fastfetch、そしてお好みのシェル。
  • 対応ディストリビューションの正式で常に最新の一覧はソースコードにあります。GitHub リポジトリをご覧ください。
