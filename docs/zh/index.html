为什么选择 ATT

绝不是黑盒

系统工具最让人沮丧的，就是不知道它对你的机器做了什么。ATT 反其道而行：每个操作都会自我说明，控制台输出就在那里，供你阅读、学习，下次自己动手运行。

  • 之前 在动任何东西之前，你都能先看到这个操作会改变什么，可能是确认对话框，也可能是一行简单的说明。
  • 期间 你可以实时看着它进行：进度、当前步骤，以及运行时的控制台实时输出。
  • 之后 你会得到一份实际改动的摘要：写入了哪些文件、安装了哪些软件包、动了哪些服务。

安装

两步即可开始使用

ATT 通过 nemesis_repo 发布，这是一个带签名的 pacman 软件源。只需添加一次软件源，然后像安装其他软件包一样安装 ATT。下面都是普通命令，运行前你可以先读一遍。

第 1 步：把软件源添加到 /etc/pacman.conf

[nemesis_repo]
Server = https://erikdubois.github.io/$repo/$arch

更喜欢脚本？它做的是同样的事

$ curl -sL bit.ly/nemesis-repo | sudo bash
关于签名。 nemesis_repo 由 Kiro 密钥进行 PGP 签名，通过 kiro-keyring 建立信任，并继承你的全局 SigLevel。如果你在安装该密钥环之前就手动添加软件源，请先为这个软件源设置 SigLevel = Optional，等密钥环装好后再改回来。

第 2 步：更新并安装

$ sudo pacman -Sy
$ sudo pacman -S archlinux-tweak-tool

然后从应用程序菜单启动 ArchLinux Tweak Tool。只有在某个操作确实需要时，它才会请求管理员权限。

兼容性

为 Arch 而生，在 Arch 系系统上同样如鱼得水

ATT 诞生于 ArcoLinux，如今可以在原版 Arch 以及人们实际在用的 Arch 系系统上运行，比如 Artix、Manjaro、CachyOS、Kiro 等等。当某个发行版有自己的做法时，ATT 会检测到并调整界面去适应，而不是与之对抗。

  • 你需要： 一个 Arch 或 Arch 系系统、Python 3.8 或更高版本、GTK 4.6 或更高版本，以及 pacman。
  • 部分页面可选： 用于软件包操作的 alacritty、fastfetch，以及你常用的 Shell。
  • 受支持发行版的权威且始终最新的列表在源码中，请查看 GitHub 仓库。
