Perché ATT

Mai una scatola nera

La cosa più frustrante di uno strumento di sistema è non sapere cosa ha fatto alla tua macchina. ATT è pensato al contrario: ogni azione si spiega da sola, e l’output della console è lì perché tu lo legga, ci impari e la prossima volta lo esegua da solo.

  • Prima Vedi cosa cambierà un’azione, con una finestra di conferma o una semplice etichetta, prima che venga toccato qualcosa.
  • Durante Vedi cosa succede: l’avanzamento, il passaggio in corso e l’output della console in tempo reale mentre l’azione è in esecuzione.
  • Dopo Ricevi un riepilogo di ciò che è cambiato davvero: file scritti, pacchetti installati, servizi toccati.

Installazione

Due passaggi e sei operativo

ATT arriva da nemesis_repo, un repository pacman firmato. Aggiungi il repository una volta sola, poi installa ATT come qualsiasi altro pacchetto. Tutto ciò che segue è un normale comando che puoi leggere prima di eseguirlo.

Passaggio 1: aggiungi il repository a /etc/pacman.conf

[nemesis_repo]
Server = https://erikdubois.github.io/$repo/$arch

Preferisci uno script? Fa la stessa cosa

$ curl -sL bit.ly/nemesis-repo | sudo bash
A proposito della firma. nemesis_repo è firmato con PGP dalla chiave di Kiro, considerata attendibile tramite kiro-keyring, e rispetta il tuo SigLevel globale. Se aggiungi il repository a mano prima di installare quel portachiavi, imposta SigLevel = Optional per questo repository finché non è a posto.

Passaggio 2: aggiorna e installa

$ sudo pacman -Sy
$ sudo pacman -S archlinux-tweak-tool

Poi avvia ArchLinux Tweak Tool dal menu delle applicazioni. Chiede i privilegi di amministratore solo quando un’azione ne ha davvero bisogno.

Compatibilità

Nato per Arch, a suo agio sui sistemi basati su Arch

ATT è nato su ArcoLinux e oggi gira su Arch pura e sui sistemi basati su Arch che la gente usa davvero: Artix, Manjaro, CachyOS, Kiro e molti altri. Dove una distribuzione fa le cose a modo suo, ATT lo rileva e adatta l’interfaccia invece di combatterla.

  • Ti serve: un sistema Arch o basato su Arch, Python 3.8 o successivo, GTK 4.6 o successivo e pacman.
  • Facoltativi, per alcune pagine: alacritty per le operazioni sui pacchetti, fastfetch e la shell che preferisci.
  • L’elenco ufficiale e sempre aggiornato delle distribuzioni supportate si trova nel codice sorgente: vedi il repository GitHub.
