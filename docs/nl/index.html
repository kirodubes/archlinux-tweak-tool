Waarom ATT

Nooit een black box

Het meest frustrerende aan een systeemtool is niet weten wat die met je machine heeft gedaan. ATT is omgekeerd opgebouwd: elke actie legt zichzelf uit, en de console-uitvoer staat er zodat je die kunt lezen, ervan kunt leren en de volgende keer zelf kunt uitvoeren.

  • Voor Je ziet wat een actie gaat wijzigen, in een bevestigingsvenster of op een duidelijk label, voordat er iets wordt aangeraakt.
  • Tijdens Je ziet het gebeuren: de voortgang, de huidige stap en live console-uitvoer terwijl het loopt.
  • Na Je krijgt een samenvatting van wat er echt is gewijzigd: geschreven bestanden, geïnstalleerde pakketten, aangepaste diensten.

Installeren

Twee stappen en je bent klaar

ATT wordt geleverd via nemesis_repo, een ondertekende pacman-repository. Voeg de repo één keer toe en installeer ATT daarna zoals elk ander pakket. Alles hieronder is een gewoon commando dat je kunt lezen voordat je het uitvoert.

Stap 1: voeg de repo toe aan /etc/pacman.conf

[nemesis_repo]
Server = https://erikdubois.github.io/$repo/$arch

Liever een script? Dat doet hetzelfde

$ curl -sL bit.ly/nemesis-repo | sudo bash
Over de handtekening. nemesis_repo is PGP-ondertekend met de Kiro-sleutel, vertrouwd via kiro-keyring en erft je globale SigLevel. Voeg je de repo met de hand toe voordat die keyring is geïnstalleerd, zet dan SigLevel = Optional voor deze repo tot het zover is.

Stap 2: bijwerken en installeren

$ sudo pacman -Sy
$ sudo pacman -S archlinux-tweak-tool

Start daarna ArchLinux Tweak Tool vanuit je toepassingsmenu. Het vraagt alleen om beheerdersrechten als een actie ze echt nodig heeft.

Compatibiliteit

Gebouwd voor Arch, thuis op systemen op basis van Arch

ATT begon op ArcoLinux en draait nu op gewoon Arch en op de systemen op basis van Arch die mensen echt gebruiken: Artix, Manjaro, CachyOS, Kiro en vele andere. Waar een distributie dingen op haar eigen manier doet, herkent ATT dat en past het de interface aan in plaats van ertegen te vechten.

  • Je hebt nodig: een Arch- of Arch-gebaseerd systeem, Python 3.8 of nieuwer, GTK 4.6 of nieuwer en pacman.
  • Optioneel, voor sommige pagina's: alacritty voor pakketacties, fastfetch en de shell van je keuze.
  • De betrouwbare, altijd actuele lijst met ondersteunde distributies staat in de broncode: zie de GitHub-repository.
