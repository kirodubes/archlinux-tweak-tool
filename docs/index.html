You know what you want your system to do — a different kernel, a nicer login screen, a theme that matches, services cleaned up. Why ATT

Never a black box

The most frustrating thing about a system tool is not knowing what it did to your machine. ATT is built the other way round — every action explains itself, and the console output is there for you to read, learn from, and run yourself next time.

  • Before You see what an action will change — a confirmation dialog or a plain label — before anything is touched.
  • During You watch it happen: progress, the current step, and live console output while it runs.
  • After You get a summary of what actually changed — files written, packages installed, services touched.

Install

Two steps and you are running

ATT ships from nemesis_repo, a signed pacman repository. Add the repo once, then install ATT like any other package. Everything below is a normal command you can read before you run it.

Step 1 — add the repo to /etc/pacman.conf

[nemesis_repo]
Server = https://erikdubois.github.io/$repo/$arch

Prefer a script? This does the same thing

$ curl -sL bit.ly/nemesis-repo | sudo bash
About the signature. nemesis_repo is PGP-signed by the Kiro key, trusted through kiro-keyring, and it inherits your global SigLevel. If you are adding the repo by hand before that keyring is installed, set SigLevel = Optional for this repo until it is in place.

Step 2 — update and install

$ sudo pacman -Sy
$ sudo pacman -S archlinux-tweak-tool

Then launch ArchLinux Tweak Tool from your application menu. It asks for administrative rights only when an action genuinely needs them.

Compatibility

Built for Arch, at home on Arch-based systems

ATT started life on ArcoLinux and now runs on plain Arch and on the Arch-based systems people actually use — Artix, Manjaro, CachyOS, Kiro and many more. Where a distribution does things its own way, ATT detects it and adapts the interface instead of fighting it.

  • You need: an Arch or Arch-based system, Python 3.8 or later, GTK 4.6 or later, and pacman.
  • Optional, for some pages: alacritty for package operations, fastfetch, and your shell of choice.
  • The authoritative, always-current list of supported distributions lives in the source — see the GitHub repository.
