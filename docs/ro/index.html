De ce ATT

Niciodată o cutie neagră

Cel mai frustrant lucru la o unealtă de sistem este să nu știi ce a făcut cu calculatorul tău. ATT este construit invers: fiecare acțiune se explică singură, iar ieșirea din consolă este acolo ca s-o citești, să înveți din ea și s-o rulezi tu însuți data viitoare.

  • Înainte Vezi ce va schimba o acțiune, printr-o fereastră de confirmare sau o etichetă simplă, înainte să fie atins ceva.
  • În timpul acțiunii Vezi cum se desfășoară: progresul, pasul curent și ieșirea din consolă în direct, cât timp rulează.
  • După Primești un rezumat al celor schimbate de fapt: fișiere scrise, pachete instalate, servicii atinse.

Instalare

Doi pași și rulezi

ATT vine din nemesis_repo, un depozit pacman semnat. Adaugă depozitul o singură dată, apoi instalează ATT ca orice alt pachet. Tot ce urmează este o comandă obișnuită pe care o poți citi înainte s-o rulezi.

Pasul 1: adaugă depozitul în /etc/pacman.conf

[nemesis_repo]
Server = https://erikdubois.github.io/$repo/$arch

Preferi un script? Face același lucru

$ curl -sL bit.ly/nemesis-repo | sudo bash
Despre semnătură. nemesis_repo este semnat PGP cu cheia Kiro, de încredere prin kiro-keyring, și moștenește SigLevel-ul tău global. Dacă adaugi depozitul manual înainte să fie instalat acel inel de chei, setează SigLevel = Optional pentru acest depozit până când este la locul lui.

Pasul 2: actualizează și instalează

$ sudo pacman -Sy
$ sudo pacman -S archlinux-tweak-tool

Apoi pornește ArchLinux Tweak Tool din meniul de aplicații. Cere drepturi de administrator doar când o acțiune chiar are nevoie de ele.

Compatibilitate

Făcut pentru Arch, ca acasă pe sistemele bazate pe Arch

ATT a început pe ArcoLinux și rulează acum pe Arch pur și pe sistemele bazate pe Arch pe care oamenii le folosesc cu adevărat: Artix, Manjaro, CachyOS, Kiro și multe altele. Acolo unde o distribuție face lucrurile în felul ei, ATT detectează acest lucru și adaptează interfața în loc să se lupte cu ea.

  • Ai nevoie de: un sistem Arch sau bazat pe Arch, Python 3.8 sau mai nou, GTK 4.6 sau mai nou și pacman.
  • Opțional, pentru unele pagini: alacritty pentru operațiunile cu pachete, fastfetch și shell-ul tău preferat.
  • Lista oficială și mereu actualizată a distribuțiilor acceptate se află în codul sursă: vezi depozitul GitHub.
