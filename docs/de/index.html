Du weißt, was dein System tun soll: ein anderer Kernel, ein schönerer Anmeldebildschirm, ein passendes Theme, aufgeräumte Dienste. ATT packt all das in ein einziges Fenster und sagt dir genau, was es tun wird, bevor es es tut. Nichts ist versteckt, nichts ist Magie, und die Befehle bleiben deine zum Lernen.

Warum ATT

Nie eine Blackbox

Das Frustrierendste an einem Systemwerkzeug ist, nicht zu wissen, was es mit deinem Rechner gemacht hat. ATT ist genau andersherum gebaut: Jede Aktion erklärt sich selbst, und die Konsolenausgabe steht zum Lesen bereit, damit du daraus lernst und es beim nächsten Mal selbst ausführen kannst.

  • Vorher Du siehst, was eine Aktion ändern wird, in einem Bestätigungsdialog oder auf einem klaren Label, bevor irgendetwas angefasst wird.
  • Währenddessen Du siehst zu, wie es passiert: Fortschritt, aktueller Schritt und Live-Konsolenausgabe, während es läuft.
  • Danach Du bekommst eine Zusammenfassung dessen, was sich tatsächlich geändert hat: geschriebene Dateien, installierte Pakete, berührte Dienste.

Installieren

Zwei Schritte und du bist startklar

ATT kommt aus nemesis_repo, einem signierten pacman-Repository. Füge das Repo einmal hinzu und installiere ATT dann wie jedes andere Paket. Alles unten ist ein normaler Befehl, den du lesen kannst, bevor du ihn ausführst.

Schritt 1: das Repo zu /etc/pacman.conf hinzufügen

[nemesis_repo]
Server = https://erikdubois.github.io/$repo/$arch

Lieber ein Skript? Das macht dasselbe

$ curl -sL bit.ly/nemesis-repo | sudo bash
Zur Signatur. nemesis_repo ist mit dem Kiro-Schlüssel PGP-signiert, wird über kiro-keyring als vertrauenswürdig eingestuft und übernimmt dein globales SigLevel. Wenn du das Repo von Hand hinzufügst, bevor dieser Schlüsselbund installiert ist, setze für dieses Repo SigLevel = Optional, bis er vorhanden ist.

Schritt 2: aktualisieren und installieren

$ sudo pacman -Sy
$ sudo pacman -S archlinux-tweak-tool

Starte danach ArchLinux Tweak Tool aus deinem Anwendungsmenü. Es fragt nur dann nach Administratorrechten, wenn eine Aktion sie wirklich braucht.

Kompatibilität

Für Arch gebaut, zu Hause auf Arch-basierten Systemen

ATT begann auf ArcoLinux und läuft heute auf reinem Arch und auf den Arch-basierten Systemen, die Menschen tatsächlich nutzen: Artix, Manjaro, CachyOS, Kiro und viele mehr. Wo eine Distribution Dinge auf ihre eigene Art macht, erkennt ATT das und passt die Oberfläche an, statt dagegen anzukämpfen.

  • Du brauchst: ein Arch- oder Arch-basiertes System, Python 3.8 oder neuer, GTK 4.6 oder neuer und pacman.
  • Optional, für einige Seiten: alacritty für Paketoperationen, fastfetch und die Shell deiner Wahl.
  • Die maßgebliche, stets aktuelle Liste der unterstützten Distributionen steht im Quellcode: siehe das GitHub-Repository.
